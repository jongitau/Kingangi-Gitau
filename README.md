## Current Research

I am completing an MSc in Data Science, with research focused on:

**Deep Learning for Improved Clinical Decision Support in Epilepsy**

My research explores how longitudinal EMR data can be transformed into patient-level timelines and used with BERT-based natural-language question answering to improve access to patient-specific clinical evidence.

The research involved:

* 35,480 de-identified clinical consultation records
* 5,639 unique patients
* 42,189 clinical text chunks
* Longitudinal EMR data processing
* Domain-adaptive BERT pretraining
* Extractive question answering
* Hybrid information retrieval
* Model evaluation using Exact Match, precision, recall and F1
* Retrieval evaluation using Recall@5 and MRR@5
* Calibrated rejection of unsupported questions

The research achieved **79.80% overall F1** on the protected end-to-end test set, while also identifying retrieval completeness and ranking as important limitations.

The system is intended as a clinical information-access prototype rather than an autonomous diagnostic or treatment system.
